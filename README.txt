Laundry2Door Pro Website
========================

This package is a standalone multi-page website.

FILES
- index.html — homepage
- residential-laundry.html
- accommodation-laundry.html
- linen-hire.html
- changeover-makeover.html
- light-cleaning.html
- service-area.html
- contact.html — booking/contact page
- styles.css — shared design
- script.js — mobile menu + booking-to-WhatsApp
- assets/ — supplied Laundry2Door banner and cropped logo

HOW TO USE
1. Unzip the package.
2. Open index.html to preview the site.
3. Upload the whole folder to your web host, or use the HTML files in Google Sites if you are embedding individual sections.
